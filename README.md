# Чекліст нульової сесії

Чекліст для майстрів настільних рольових ігор: про що домовитись до першої гри. Матеріал до воркшопу «Безпека й керування групою».

## Файли

- `index.html` — інтерактивна версія. Один самодостатній файл, працює без інтернету: відмітки пунктів, світла й темна тема, адаптація під телефон і друк.
- `chekslist-nulovoi-sesii-A4.pdf` — готова версія для друку на A4.
